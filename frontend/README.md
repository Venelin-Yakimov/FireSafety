# Пожарна безопасност — фронтенд

Тази папка е предназначена за клиентската част на проекта „Пожарна безопасност“.

## Състояние

Фронтенд приложението още не е създадено. В момента тук има само този README, за да се вижда папката в GitHub и да е ясно за какво е предназначена.

Когато започне разработката, тук ще бъдат добавени интерфейсът за клиенти, специалисти и администратор, както и инструкциите за инсталиране и стартиране.

## Връзка с бекенда

API проектът е в [`../FireSafety.Api`](../FireSafety.Api/README.md). Адресът на API ще бъде описан тук, когато бъдат добавени крайните точки и фронтендът започне да ги използва.
